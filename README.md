# `expressive-code-collapsible` 🔋

An Expressive Code plugin to expand or collapse code blocks.

## Package

If you are looking for the Starlight plugin package, you can find it in the [`packages/expressive-code-collapsible/`](/packages/expressive-code-collapsible/) directory.

## Project structure

This project uses pnpm workspaces to develop a single Starlight plugin from the `packages/expressive-code-collapsible/` directory. A Starlight documentation site is also available in the `docs/` directory that is also used for testing and demonstrating the Starlight plugin.
